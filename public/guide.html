How to read this lab

← back to the lab

Every production AI system has three layers. This lab builds a miniature one and lets you break each layer independently — because each layer fails with a signature symptom, the symptom tells you which layer is broken before you touch the model.

The three layers

  • Harness — what the agent can access: tools, filesystem, permissions, memory. In this lab it's public/harness.mjs: a tool registry plus a read/write scope. Remove read_file or deny workspace/ and the model can't reach reality — it reports the fault and aborts.
  • Loop — how the agent thinks: think → act → check → feedback. In public/loop.mjs, turning feedback: false drops every observation. The scripted model can't see its own results, so it re-issues the same call until the step cap — the "spinning" symptom. The stallGuard preset shows the fix: progress detection that stops the spin early.
  • Graph — how work splits: nodes, parallel branches, joins, shared state. In public/graph.mjs two analysts read-modify-write the same findings key. In flat mode the second write silently overwrites the first — a lost update. In versioned mode the stale write is a conflict that retries and merges.

What the atlas does

public/atlas.mjs reads a run report and maps the symptom to the layer: blocked/missing tool calls → harness, identical repeated calls or a step-cap stop → loop, lost updates on shared state → graph. That's the article's argument made executable: debug by layer, not by vibes.

Honest limits

  • The "model" (public/model.mjs) is a deterministic state machine, not an LLM — the lab shows where failures live, not how a real model reasons.
  • The graph runner simulates interleaving in one process; real distributed workflows add partial failure, retries across processes, and ordering guarantees this demo doesn't model.
  • Diagnosis rules are the three signature symptoms — real systems have faults that cross layers (a dying tool can look like a spinning loop).
  • The world is a fixture: fake files, fake docs index, obviously-fake secret in secrets/prod.env.
